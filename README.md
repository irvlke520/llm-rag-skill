# build-llm-rag-service

一个 Claude / Codex / DSH 风格的 Agent Skill：**从零搭一个带检索增强（RAG）的 LLM 问答服务**。

不是一段代码，是一份能直接照着做的操作手册——从文档切分、向量化、检索、拼 prompt，到 FastAPI 接口和 Docker 部署，每一步都写了为什么这么做、以及常见的坑。

## 这个 skill 解决什么

把自己的资料（md / pdf / txt）变成能问答的服务，是最常见的 LLM 应用需求，但也是最容易做歪的：

- 切分切碎了，检索命中但上下文不够，回答跑题
- 切太大了，一块混好几个主题，检索不准
- 入库用 A 模型、查询用 B 模型，检索直接失效
- prompt 不约束，模型开始编造
- 没做超时和重试，线上偶发卡死

这份 skill 把这些点的处理方式固定下来，照着走能避开大部分返工。

## 怎么用

**方式一：当普通文档读**

直接看 [`SKILL.md`](./SKILL.md)，按章节推进。

**方式二：装进支持 Skill 的 Agent**

把 `SKILL.md` 放进对应客户端的 skills 目录：

```
~/.claude/skills/build-llm-rag-service/SKILL.md
~/.agents/skills/build-llm-rag-service/SKILL.md
```

之后让 Agent 做 RAG 相关的活，它会自动加载。

## 适用 / 不适用

**适用**

- 自建一个基于自己资料的问答服务
- 给内部文档做检索入口
- 学习 RAG 的标准流程

**不适用**

- 需要微调模型（这里只讲调用接口）
- 多模态（纯文本）
- 超大规模（百万级文档需要换更专业的检索方案）
